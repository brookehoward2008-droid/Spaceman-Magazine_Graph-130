Project Information

This final project uses original Spacemen magazine page references, semantic HTML, responsive CSS, and a wide editorial layout built to feel closer to a desktop magazine spread than a narrow web page.

I started by experimenting with Flexbox because it helped me quickly arrange the page content and test how the images and text could stack on smaller screens. As the design developed, I changed the main layout direction toward CSS Grid because it gave me better control over the magazine structure. Grid made it easier to organize rows, columns, image areas, captions, pull quotes, and article sections in a way that felt closer to a printed magazine layout.

I used InDesign to study page structure, spacing, image placement, and visual hierarchy before translating the layout into HTML and CSS. I also used Affinity to optimize the photos for web use and add color treatment so the images felt more connected to the vintage space-magazine style. The Internet Archive was used as a resource for vintage magazine imagery and article inspiration.

The working page frame is set to 97vw with a 2200px maximum width. The reference page uses a 96vw frame with a 1900px maximum width, three equal desktop columns, two columns on tablet, and one column on mobile.

The main magazine pages use a flexible spread system: hero image and story panel first, supporting copy blocks below, then a full-width pull quote and image gallery. Desktop image/story spreads balance around 62% image and 38% text, with the Moon page kept full-width so the rocket scan can breathe.

The images were saved for the web so the pages would load more efficiently while still keeping the visual style of the original magazine reference.
